# Если после заставок остаётся чёрный экран

Буква диска сама по себе сбой не объясняет. Сначала выясните, что именно не
запускается: игра с BepInEx без мода или мод. Не переносите игру и не меняйте
системные настройки до проверки журналов.

## Отделить загрузчик от плагина

Все изменения файлов делайте при закрытой игре. Сохранения не удаляйте.

1. Временно вынесите `BepInEx/plugins/ZompiercerLAN.dll` и папку
   `BepInEx/plugins/ZompiercerLAN.Network` за пределы папки игры. Если других
   плагинов нет, получится BepInEx без мода. Проверьте запуск вручную.
2. Если экран остаётся чёрным, временно переименуйте установленный с BepInEx
   `winhttp.dll` в `winhttp.dll.disabled`. Проверьте обычную игру, затем верните
   имя файла. Если это помогает, исследуйте загрузчик и другие плагины.
3. Если BepInEx без ZompiercerLAN работает, верните файлы мода и обновите
   мод до одной версии на обоих компьютерах. Не смешивайте DLL и сетевой
   помощник из разных выпусков; не оставляйте вторую копию DLL в plugins.
4. Сразу после проблемного запуска сохраните `BepInEx/LogOutput.log`.
   Важны первая ошибка со стеком и строки перед ней, а не только последняя
   строка. Если файла нет, нужен журнал Unity: сбой мог произойти до запуска
   BepInEx.

Для явного журнала Unity игрок может вручную выполнить в PowerShell,
открытом в папке с `Zompiercer.exe`:

```powershell
& .\Zompiercer.exe -logFile (Join-Path $env:TEMP 'Zompiercer-startup.log')
```

Файл `Zompiercer-startup.log` появится во временной папке Windows. Перед
передачей журналов уберите личные пути, имя компьютера, адреса и секреты.
Конфиги, сохранения и файлы идентификации игрока публиковать не нужно.

## Что искать

- `UnauthorizedAccessException`, `Access denied`: проверьте, может ли обычный
  пользователь записывать в `BepInEx/config`. Особенно существенно для
  установки в защищённой папке `Program Files`; буква диска роли не играет.
- `FileNotFoundException`, `BadImageFormatException`: проверьте полноту архива,
  Windows x64 и загрузчик BepInEx 5 для Unity Mono.
- `HarmonyException`, `MissingMethodException`: возможны другая версия игры,
  несовместимые библиотеки или другой плагин. Нужен полный стек ошибки.
- Начиная с 1.1.2 в журнале есть строки `LAN startup: ...` и `LAN startup completed`: они
  показывают, до какого этапа дошла инициализация плагина. Сетевой помощник
  запускается по действию в LAN, а не при появлении заставок. Его ошибка
  изоляции сама по себе не доказывает причину чёрного экрана до меню.

Не запускайте игру администратором и не отключайте защиту Windows для обхода
ошибок. Изменения загрузчика выбирайте по конкретной ошибке из журнала.

Источники: [диагностика BepInEx](https://docs.bepinex.dev/articles/user_guide/troubleshooting.html),
[аргумент Unity 2020.1 -logFile](https://docs.unity.cn/2020.1/Documentation/Manual/CommandLineArguments.html).
